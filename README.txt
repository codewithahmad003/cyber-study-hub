CYBER STUDY HUB - kaise chalayein
1. Is ZIP ko extract karein (right-click > Extract All). Folder ka naam "Cyber_Study_Hub" hoga.
2. "study_hub" folder kholein aur "index.html" par double-click karein (Chrome ya Edge mein khulega).
3. Internet ke baghair bhi chalta hai. Resources ke links kholne ke liye internet chahiye.
4. Aap ki progress (ticks, notes, timer, scores) isi browser mein save hoti hai.
   - File ko baar baar jagah na badlein, aur hamesha isi browser mein kholein.
   - Hafte mein ek dafa: Progress & settings > "Download backup (.json)".
5. "pdfs" folder study_hub ke saath hi rehna chahiye, taa ke "Open PDF" buttons chalein.
